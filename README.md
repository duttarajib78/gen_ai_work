## Featured Projects

### 1. DRG Audit Anomaly Detector
**Advanced ML · Transformer Architectures · Contrastive Learning · Anomaly Detection**

A machine learning project focused on identifying potential discrepancies in Australian hospital diagnosis-related group (DRG) assignments.

- Transformer-based representation learning and contrastive pretraining.
- Cascaded classification for hierarchical DRG prediction.
- Attention to data leakage, class imbalance, and model validation.
- Anomaly scoring and prioritisation of cases for further review.

**Focus:** Applying advanced machine learning to complex, high-dimensional structured data.

[**Explore the project →**](https://github.com/duttarajib78/gen_ai_work/tree/main/drg-audit-anomaly-detector)

### 2. Admissions Audit Agent
**Generative AI · LLM Reasoning · Decision Support · Human-in-the-Loop AI**

An LLM-assisted workflow for reviewing coded hospital diagnoses against associated procedures, services, and episode-level evidence.

- Structured diagnosis-level assessments and model outputs.
- Validation and rule-based checks to support consistent decisions.
- Proposed coding corrections and downstream regrouping workflows.
- Human review and privacy-conscious handling of sensitive information.

**Focus:** Applying LLMs to domain-specific decision support while retaining explicit validation and human oversight.

[**Explore the project →**](https://github.com/duttarajib78/gen_ai_work/tree/main/admissions-audit-agent)

## Engineering Principles

I aim to build AI systems that are:

- **Evidence-driven:** Evaluated against appropriate baselines and clearly defined objectives.
- **Reproducible:** Supported by documented methods, controlled experiments, and repeatable workflows.
- **Reliable:** Designed with input validation, error handling, and operational constraints in mind.
- **Auditable:** Transparent about assumptions, limitations, and the role of human review.
- **Purpose-built:** Designed around the underlying problem rather than the novelty of a particular technology.
