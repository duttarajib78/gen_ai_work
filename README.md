# Rajib Dutta
### Data Scientist | Applied AI & Machine Learning | AI Systems Engineering

I build machine learning and AI systems that turn complex data and domain knowledge into actionable, auditable decisions.

My work spans **advanced machine learning, transformer-based modelling, generative AI, agentic systems, and production-oriented AI engineering**, with a particular interest in healthcare analytics and decision support.

## Featured Projects

### 1. DRG Audit Anomaly Detector
**Transformer-based modelling · Contrastive learning · Anomaly detection**

A machine learning system designed to identify potential discrepancies in Australian hospital diagnosis-related group (DRG) assignments.

- Contrastive pretraining and transformer-based representation learning.
- Cascaded classification for hierarchical DRG prediction.
- Leakage-aware validation and class-imbalance handling.
- Model serving, anomaly scoring, and audit prioritisation.

[Explore the project →](https://github.com/duttarajib78/gen_ai_work/tree/main/drg-audit-anomaly-detector)

### 2. Admissions Audit Agent
**LLMs · Clinical decision support · Structured reasoning**

An LLM-assisted workflow for reviewing whether coded hospital diagnoses are clinically supported by associated procedures and billed services.

- Structured diagnosis-level assessments.
- Validated model outputs and explicit decision rules.
- Proposed coding corrections and downstream regrouping.
- Privacy-conscious input handling and human-review workflows.

[Explore the project →](https://github.com/duttarajib78/gen_ai_work/tree/main/admissions-audit-agent)

### 3. Diagnosis Supporting Lists
**Generative AI · Knowledge extraction · Healthcare analytics**

An LLM-assisted system for identifying potentially relevant procedure codes, medical billing items, and related diagnoses for ICD-10-AM categories.

- Domain-specific evidence assessment.
- Structured outputs with validation.
- Batch processing, caching, and service-oriented architecture.
- Human review for clinical coding decisions.

[Explore the project →](https://github.com/duttarajib78/gen_ai_work/tree/main/dx-supporting-lists)

### 4. Rule Extraction Service
**Agentic AI · Knowledge engineering · Reliable processing**

An agent-based pipeline for extracting Australian hospital coding and compliance rules into structured, machine-executable representations.

- Document and coding-standard ingestion.
- Structured rule extraction and validation.
- Asynchronous job processing and durable state management.
- Human verification, security controls, and operational safeguards.

[Explore the project →](https://github.com/duttarajib78/gen_ai_work/tree/main/rule-extraction-service)

## Engineering Principles

I aim to build AI systems that are:

- **Evidence-driven:** evaluated against appropriate baselines and explicit objectives.
- **Reproducible:** supported by clear documentation, controlled experiments, and tests.
- **Reliable:** designed with input validation, failure handling, and operational constraints in mind.
- **Auditable:** transparent about assumptions, limitations, and the role of human review.

## Current Focus
